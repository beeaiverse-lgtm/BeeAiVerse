Change Your Password

Password changes are done securely via your Google Authenticator code — no email required.

How to change your password:

  1. Log in with your User ID and password
  2. Complete your Google Authenticator 2FA check
  3. Go to Profile → Change Password
  4. Enter your current password + a fresh authenticator code

This approach is more secure than email OTP and works even if your email inbox is inaccessible.
